- **字数**：线上约为 v17 的 **2.16 倍**。

- **响应时间**：v17 ~30s，线上 ~45–74s。

## 二、质性差异（共性 + 差距）

### 共性（两者都做到）
- 核心结论**一致**（10 题逐一核对，方向性结论无冲突）。
- 都遵循 **PICO → 4 库检索 → 分层证据 → 临床决策** 的循证范式。
- 都用 `[^xx-xxxx-x]` 引用体系、严格分层（01/02/03/04）。

### 线上明显更强的地方
1. **效应量具体**：大量 `RR / 95%CI / HR / 样本量`。
   - 例（q08 脓毒症）：`病死率 RR 0.99, 95%CI 0.89–1.08`、`13 项 RCT 合计约 4006 例`、CLOVERS 晚期 CKD 亚组 `HR 0.50, 95%CI 0.29–0.85`。
2. **点名具体试验**：CLOVERS、REVERSE-AKI、REDUCE 等，可核查性强。
3. **临床 nuance / 亚组**：能区分"一般人群 vs 合并晚期 CKD 亚组"，并说明证据来自事后亚组分析、不能外推。
4. **决策表格化**：第三部分"临床实践决策"常是**分场景表格**（初始复苏 / 优化阶段 / 已发生 AKI / 合并 CKD / 有容量反应性），落地性强。
5. **证据卡可视化**（messageType=61）：每张卡带 RCT/指南标签 + doc_id + 标题。

### v17 不输 / 优势
1. **核心结论正确**且与线上一致（如 q08 都判定"无高质量证据支持限制性补液降低 AKI/28天病死率"）。
2. **格式规范、引用真实、零幻觉、无退化**（已是自训练 14B 的高水准）。
3. **更简洁**（约一半篇幅），**响应更快**（~30s vs ~60s）——在需要快速决策的场景反而是优点。

## 三、典型样例（q08 脓毒症休克）

- **v17**（14 引用 / 1047 字）：四层结构清晰，结论正确，但多为定性描述，具体效应量少。
- **线上**（7 引用 / 2942 字）：给出 `RR 0.99 (0.89–1.08)`、CLOVERS 亚组 `HR 0.50 (0.29–0.85)`、5 张证据卡（REVERSE-AKI / REDUCE / CLOVERS 二次分析 / 优化限制性策略 RCT / ESICM 2025 指南），并用 5 行决策表覆盖不同临床场景。

完整文本见 `data/comparison_v17_vs_online.md` 的 Q08 段。

## 四、判读

> v17 与线上的差距，**不是检索架构或模型基本能力的差距**（两者同架构、结论一致、v17 引用真实零幻觉），而是：
> 1. **证据颗粒度**——线上 top10 不截断喂入大量带数字的原文，使其能写出具体 RR/CI/试验名（根因分析见 [06](06_context_length_retrieval_analysis.md)）；
> 2. **工程化呈现**——决策表格、证据卡渲染；
> 3. **可能更大的模型 / 更强的 prompt**。

这意味着 v17 的提升空间主要在**检索规模对齐 + 输出工程化**，而非推倒重来。
