# 06 · 上下文长度 × 检索规模测算

## 问题

线上回答比 v17 长约 2 倍、数字更多。用户确认根因：**线上 = top10 + 不截断；本地 = top2 + 1500 字截断**。即"回答的详细程度主要由喂给模型的证据量决定"，不是在 prompt 里写字数要求能凑出来的。

本文量化：**v17 底座（Qwen2.5-14B）在不同 `max-model-len` 下，能支撑多少篇不截断文档**。

## 模型上下文上限

- Qwen2.5-14B 原生 `max_position_embeddings = 32768`（32K）。
- 可用 **YaRN rope scaling** 扩到 48K/64K/128K——可行，但**牺牲部分质量**、KV cache 显存上升（80G 卡显存不是瓶颈，质量才是）。

## Token 预算分解

一次推理上下文 = 固定开销 + 证据 + 输出留白：

| 占用项 | 估算 token |
|---|---|
| system prompt（prompt_new 全文） | ~1800 |
| 工具定义 + 问题 + 工具调用 | ~350 |
| 输出留白（线上答案 ~2600 字 ≈ 2500 tok） | ~2500 |
| **固定开销合计** | **~5000** |

→ **证据预算 ≈ max-model-len − 5000**

每篇文档 token 成本（中英混排医学文本，约 1 token ≈ 2 字符）：
- 截断版（1500 字）：~750 token/篇
- **不截断**（摘要 + 1 个内容块，约 1500–2000 字）：**~900 token/篇**

## 测算表：不同 max-model-len 支撑的不截断文档数

| max-model-len | 证据预算 | 不截断可支撑 | ≈ 每库 top-k | rope scaling |
|---|---|---|---|---|
| **12000（现状）** | ~7000 | ~7–8 篇 | 现为 top2+截断=8篇 | 否 |
| 16384 | ~11000 | ~12 篇 | top3 | 否 |
| **32768（原生上限）** | ~27000 | **~28–30 篇** | **top7–8** | 否 |
| 49152 | ~44000 | ~48 篇 | top10+ 富余 | 是（YaRN） |
| 65536 | ~60000 | ~65 篇 | top10 无压力 | 是（YaRN） |

> 估算口径：固定开销 ~5000 token、不截断 ~900 token/篇。实际随题目/文档长度浮动 ±20%。

## 直接回答

- 线上 **top10 × 4 库 ≈ 最多 40 篇不截断**（实测每题召回 25–40 篇）。
- 完全复刻 40 篇不截断 ≈ 需 `40×900 + 5000 ≈ 41000 token` → **32K 刚好不够，需 YaRN 扩到 ~48K**。
- **最划算的甜点区**：`max-model-len 32768` + 每库 **top7~8** + 去截断 → **~28–30 篇**，**原生支持、无需 rope scaling、显存无压力**，证据量已与线上同量级。

## 显存（KV cache）参考

Qwen2.5-14B（GQA，48 层、8 KV heads、head_dim 128，bf16）KV cache ≈ **~192 KB/token**：
- 32K：~6 GB/序列
- 64K：~12 GB/序列

80G 卡上模型权重 ~28GB，余量充足 → **显存不是瓶颈**。

## ⚠️ 关键风险：训练分布外（OOD）

**v17 是在 top2 + 1500 截断（低证据量、短上下文）分布下做 GRPO 训练的。** 直接把它塞进 28–40 篇、3 万 token 的长上下文属于 **OOD**：

- 可能 **"lost in the middle"**（只用开头结尾文献、漏中间）、引用变乱、甚至退化。
- 线上 top10 不截断效果好，很可能其模型**就是按该检索规模训练/调过的**（或用了更大模型）。

**结论**：纯改 `max-model-len + top-k`，能让答案变长、数字变多，但**不保证达到线上质量**；要认真对齐线上，正路是**用 top10/不截断的配置重新训练一版**，使训练与推理的证据规模一致。

## 建议的验证实验

1. 保守甜点区：`max-model-len 32768` + 每库 `top8` + 去 1500 截断，重启 vLLM，重跑 10 题。
2. 对比该配置下 v17 的：字数、具体效应量出现率、引用真实率、**重复率**（检测 OOD 退化）。
3. 若退化明显 → 证明需重训；若稳定 → 说明仅推理放大即可显著缩小与线上差距。
